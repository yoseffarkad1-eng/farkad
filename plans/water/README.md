# תוכנית המים, מפוצלת — W‑02 / W‑03 / W‑04

גיליון `W‑01` שבסט ה‑MEP נושא את שלוש מערכות המים על שרטוט אחד: מים קרים (כחול),
מים חמים (אדום) וקו המחזור (אדום מקווקו). כאן הוא מפוצל לשלושה גיליונות A1, אחד לכל מערכת:

| גיליון | תוכן | מה נשאר מ‑W‑01 |
| --- | --- | --- |
| `W-02.pdf` | **מים קרים** | כל 105 קווי הקר, קו ראשי Ø25, כל 26 נקודות המים |
| `W-03.pdf` | **מים חמים** | כל 43 קווי החם, הדוד, 11 נקודות חם + הזנת הדוד (נק׳ 13) |
| `W-04.pdf` | **קו מחזור** | הלולאה המקווקוות Ø16, משאבת הסחרור, המגוף האל־חוזר והדוד |

## איך זה נעשה

השרטוט **לא צויר מחדש**. כל גיליון הוא זרם התוכן של W‑01 עצמו, שממנו נמחקו המערכות
האחרות: אופרטור הצביעה של כל נתיב שאינו שייך למערכת הוחלף ב‑`n`, וכל ריצת גליפים שאינה
שייכת לה נמחקה יחד עם האופרנד שלה. לכן קיר, צינור או מידה נמצאים במילימטר שבו המתכנן
שם אותם — לא במקום שאליו העתקה הייתה מגיעה. הקו הראשי Ø25 וארונות המחלקים נשארים
בשלושת הגיליונות, כרקע משותף.

מה שכן נכתב מחדש: המקרא, הסכמה, ההערות הכלליות, טבלת הנקודות והכותרת. כל מספר בהם
נקרא בחזרה מ‑W‑01 — אין בהם נתון שהגיליון המקורי לא אומר.

## הרצה מחדש

```
pip install pymupdf
python3 tools/build.py <path-to-MEP_Rev02_Print_A1.pdf>    # כותב W-02/03/04.pdf
python3 tools/verify.py <path-to-MEP_Rev02_Print_A1.pdf>   # מודד מול W-01
```

`build.py` מריץ את Chromium ללא ראש כדי להדפיס את הבלוקים החדשים (עברית RTL,
DejaVu Sans — אותו גופן שבגיליון המקורי) ומטביע אותם בחורים שנחתכו בגיליון.

`verify.py` סופר, בתוך חלון השרטוט בלבד, כמה מנתיבי כל צבע של W‑01 שרדו בכל גיליון וכמה
נתיבים זרים נותרו, ובודק אילו בלוני מספור מופיעים. הוא מסתיים ב‑`FAILURES: 0` כשהפיצול נקי.
