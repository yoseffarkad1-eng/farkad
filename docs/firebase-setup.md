# הגדרת סנכרון בין המכשירים

עד שהשלבים כאן יבוצעו, האפליקציה עובדת בדיוק כמו קודם: הכל נשמר במכשיר הזה בלבד.
אין צורך למהר — אפשר להמשיך לעבוד ולבצע את ההגדרה מתי שנוח.

**עלות: אפס.** התוכנית החינמית של Firebase נותנת 50,000 קריאות ו-20,000 כתיבות ביום.
לוח של 30 עובדים לא מתקרב לזה. אין צורך בכרטיס אשראי לשימוש הזה.

---

## 1. יצירת פרויקט

1. היכנס ל-<https://console.firebase.google.com> עם חשבון Google.
2. **Add project** → תן שם (למשל `farkad-schedule`) → **Continue**.
3. במסך Google Analytics בחר **Disable** — לא נחוץ, ומוסיף הרשאות מיותרות.
4. **Create project**.

## 2. הפעלת התחברות

1. בתפריט הצד: **Build → Authentication → Get started**.
2. לשונית **Sign-in method** → **Google** → **Enable**.
3. בחר Support email → **Save**.

## 3. יצירת מסד הנתונים

1. **Build → Firestore Database → Create database**.
2. בחר **Production mode** (לא Test mode — הוא פותח את המסד לכולם למשך 30 יום).
3. בחר מיקום קרוב, למשל `eur3`.

## 4. הדבקת כללי האבטחה

זה השלב שבאמת מגן על הנתונים. אל תדלג עליו.

1. **Firestore Database → Rules**.
2. מחק את מה שכתוב שם, והדבק את התוכן של `firestore.rules` מהפרויקט.
3. החלף את השורות `REPLACE-ME-...` בכתובות המייל האמיתיות. יש ארבע שורות: שלוש
   למשתמשים, ואחת רזרבית שאפשר להשאיר כמו שהיא עד שתידרש.

   **כל מי שברשימה גם רואה וגם כותב.** אין הפרדה בין צופה לעורך: שלושתכם בונים את
   הסידור יחד ומחלקים את העבודה ביניכם, ומה שמונע דריסה הדדית הוא שכל עריכה שולחת
   נתיב אחד ולא את כל המסמך.
4. **Publish**.

## 5. העתקת ההגדרות לאפליקציה

1. **Project settings** (גלגל השיניים) → גלול ל-**Your apps** → סמל `</>` (Web).
2. תן כינוי כלשהו, **בלי** לסמן Firebase Hosting → **Register app**.
3. העתק את הערכים מתוך `firebaseConfig` שמופיע במסך.
4. הדבק אותם ב-`js/sync/firebase-config.js`.

הערכים האלה אינם סוד — הם גלויים בכל אתר שמשתמש ב-Firebase. מה שמגן על הנתונים
הוא הכללים משלב 4, ורק הם.

## 6. חיבור העמוד

ב-`index.html`, הסר את סימני ההערה מהשורה:

```html
<script type="module" src="js/sync/firebase-adapter.js"></script>
```

היא חייבת להישאר `type="module"` — ה-SDK של Firebase נטען רק כמודול. שאר קובצי
ה-JS של האפליקציה חייבים להישאר קלאסיים כפי שהם, כי כל הכפתורים עובדים דרך
`onclick` שנפתר בהיקף הגלובלי.

## 7. בדיקה

1. פתח את האפליקציה במחשב → **☁️ התחבר לענן** → התחבר עם Google.
2. השורה מתחת ללוח צריכה לעבור ל־**מסונכרן בין המכשירים**.
3. הוסף עובד.
4. פתח את אותו עמוד בטלפון והתחבר עם אותו חשבון — העובד אמור להופיע.

אם משהו נכשל, פתח את ה-Console בדפדפן. שגיאת `permission-denied` פירושה כמעט תמיד
שהכתובת בשלב 4 לא זהה לכתובת שאיתה התחברת.

---

## מה זה לא פותר

- **סנכרון אינו גיבוי.** מחיקה בטעות מסתנכרנת גם היא. המשך לייצא קובץ מדי פעם.
- **הכתיבה נשארת ממכשיר אחד בכל רגע.** אין מיזוג בין שני עורכים בו-זמנית, כי
  בפועל רק אדם אחד בונה את הלוח.
